学校一般会在大一下学期以及大二开放转专业，大类招生的也会进行大类分流，想转专业的同学以及想分到热门专业的同学要做的就是努力学习来拉高自己的绩点，建议不低于3.5（取决于专业/大类的热门程度）西科大的转专业政策还是比较友好的，不过部分学院要求不同，需要提前了解相关政策。

### 转专业关键提示

- **只看大一下学期之前一学期的成绩**：大一下学期申请转专业时，**只看你大一上学期的绩点**，并不参考高考成绩或大一下学期成绩。这意味着决定权集中在第一学期，准备窗口很短。
- **不少学院有专业考试 / 面试**：很多学院的转专业除了看绩点，还需要参加专业考试或面试。需要提前通过辅导员、目标学院官网或学长学姐了解是否有笔试、考什么内容、面试侧重方向。
- **学本专业的同时留意目标专业**：转专业前你仍然要学本专业并保证绩点，但同时需要主动了解目标专业大一学过什么、有什么核心基础课、有哪些经典教材 / 项目 / 实验。面试时最常见的"翻车"就是对本专业一知半解、对目标专业一无所知。
- **想转专业的同学要更早开始收集信息**：从大一上学期甚至暑假就开始关注目标学院 / 目标专业的动态，了解课程结构、师资、研究方向，准备好面试 / 笔试常被问到的内容。
