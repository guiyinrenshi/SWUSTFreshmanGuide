# 欢迎加入 Minecraft 星空社

> 本页面由 Minecraft 星空社投稿，社区贡献者 `without007`（网名「三月七」）是星空社成员。

## 关于我们

Minecraft 星空社是西南科技大学的学生社团，聚集了一群热爱 Minecraft 及各类沙盒、生存、模组、对局类游戏的同学。无论你是刚刚接触 MC 的萌新，还是红石、建筑、PVP 高手，星空社都有适合你的位置。

## 我们在做什么

- **服务器联机**：自建生存、创造、模组服务器，常年在线
- **建筑 / 红石 / 模组 / PVP**：各方向都有活跃小组，定期组织内建与对局
- **线下活动**：校内科创园、社团活动室不定期组织面基、生日会、节日活动
- **跨校联动**：与周边高校 MC 社保持联系，偶尔组织跨校友谊赛 / 联合服务器
